# M5-19 · Supports imprimés générés depuis le plan

**Module :** M5 · Mini-site, RSVP, plan de table et rapport traiteur  
**Version :** V2

## User story

En tant que couple, je veux générer tous mes supports imprimés depuis le plan, afin de ne rien recopier.

## Critères d'acceptation

- [ ] Plan alphabétique, panneau d'entrée, cartes d'orientation, marque-places (avec icône du plat), numéros de table en nombre exact
- [ ] Seuls les invités présents
- [ ] Polices et couleurs coordonnées
- [ ] PDF prêt pour l'imprimeur (fond perdu, traits de coupe)
- [ ] Régénération d'une seule carte si un invité change

## Définition de « terminé »

- Fonctionne sur mobile et ordinateur.
- Respecte le livre de marque Sereno (couleurs, typographies, ton).
- Données sauvegardées et visibles par le co-pilote.
- Textes en français relus, termes inclusifs : partenaires désignés par leurs prénoms, jamais « la mariée » / « le marié ».
